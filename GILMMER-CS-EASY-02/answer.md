1、C语言定义指针变量：type* var_name;指针变量都是固定的，与操作系统有关。32位系统占4字节，64位占8字节，存储着所指向内存的地址。

2、
```
int x = 10;
int* p = &x;
*p = 20;

int arr[3] = {3, 6, 9};
int *q = arr;
int y = ++*arr  +  *++q;

printf("%d %d", x, y);
```

输出结果为20 10

对于x：p是指向x内存的指针，`*p = 20`，修改了内存中的数据，x就变为20了
对于y：arr是数组。`int* q = arr;`使q为指向arr数组起始位置的指针。*arr（由数组退化为指针，指向数组起始位置）解引用得到3，然后`++*arr`得到4。++q使q指针左移，指向6，在解引用得到6，6 + 4 = 10，所以y = 10

3、野指针是指向未知或非法内存的指针，由于指向未知内存，内存中的数据是垃圾值，可能导致数据损坏，至于程序崩溃。避免野指针需要避免数组越界，不使用未初始化的指针，不适用已经释放的内存指针，free后的指针应该及时置空。

4、swap函数实现：

```
void swap(int* a,int* b){
    int temp = *a;
    *a = *b;
    *b = *a;
}
```

结构体:

1、

```
typedef struct PerInfo{
    char name[10];
    char sex;
    int age;
    double height;
} Info;
```

2、结构体指针是指向结构体的指针，指向结构体内存的起始位置

3、内存对齐规则：内存对齐是指结构体内成员变量类型会存储在其所占字节的整数倍且内存总大小该结构体内存对齐数的整数倍，所以成员变量的顺序会影响结构体所占用字节数。
name占10个字节，从0开始排，sex占一个字节，目前占用11个字节。11不是4的倍数，需要填充1个字节，age占用4字节，则当前占用16个字节，height占用8个字节，16是8的倍数，无需填充，故struct PerInfo占24个字节

如交换顺序:

```
typedef struct PerInfo{
    char name[10];
    double height;
    int age;
    char sex;
} Info;
```
name占用10个字节，10不是8的倍数，填充到16，则占用24个字节，24是4的倍数，无需填充，占用28个字节，故总共占用29个字节，但不是8的整数倍，需要填充3个字节。故最终占用字节数为32
链表
1、链表通过上一个节点指向下一个节点，每一个节点存储数据完成存储。而数组则是声明一段连续的内存空间，通过下标进行访问存储数据
2、单向链表储存指向下一个节点的指针，和当前节点存储的数据。只能够单向访问

struct ListNode{
